# Portfolio Backend

Java backend for my portfolio website built with Spring Framework. This project handles authentication/authorization and CRUD functionality.

# Gettings Started

## Prerequisites

- OpenJDK 26
- PostgreSQL

## Environment variables

The project requires the following environment variables:

- PORTFOLIO_BACKEND_DB_URL
- PORTFOLIO_BACKEND_DB_USER
- PORTFOLIO_BACKEND_DB_PASSWORD
- PORTFOLIO_BACKEND_JWT_SECRET

## Installing

```
git clone https://github.com/elias4096/portfolio-backend.git
cd portfolio-backend

# Run development server
gradlew bootrun
```
